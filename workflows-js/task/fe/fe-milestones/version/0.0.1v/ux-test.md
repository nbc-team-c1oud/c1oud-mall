# [FE UX Test] 0.0.1v — 수동 검증 체크리스트

> FE 화면 수동 검증. a11y · 시각 · 플로우 · 엣지 케이스.
> **역할**: 자동 테스트로 잡히지 않는 UX 회귀 · 접근성 · 실 브라우저 조작 검증.

## 화면별 체크리스트 (FE 착수 시 채움)

### 인증 (Auth)
- [ ] 회원가입 폼 · 유효성 실패 시 inline error 표시
- [ ] 로그인 성공 후 홈 리다이렉트
- [ ] 로그인 실패 시 명확한 메시지 (U002)
- [ ] JWT 만료 후 자동 로그아웃 + 로그인 페이지 이동
- [ ] 키보드 Tab 순서 자연스러움
- [ ] 스크린 리더로 폼 라벨 읽힘

### 상품 목록 · 상세
- [ ] 상품 32건 (더미 데이터) 정상 로드
- [ ] QueryDSL 검색 · 필터 반영
- [ ] 페이지네이션 정상 동작
- [ ] 이미지 로딩 (LCP 목표 달성)
- [ ] 상품 상세 페이지에서 담기 버튼 정상 동작

### 장바구니
- [ ] 담기 → 즉시 반영 (Optimistic Update 검토)
- [ ] 수량 변경 · 개별 삭제 · 다중 선택 삭제 · 전체 비우기
- [ ] `cartItemId` 정합 (BE v3 통합 활용)
- [ ] 빈 장바구니 상태 UI
- [ ] 재고 초과 시 명확한 메시지 (`INSUFFICIENT_STOCK`)

### 주문
- [ ] 주문 미리보기 (재고 차감 없음)
- [ ] 주문 생성 → `portonePaymentId` 응답 받음
- [ ] 주문 목록 · 상세 조회
- [ ] 주문 취소 (PENDING/FAILED 상태만 가능한지 검증)

### 결제
- [ ] PortOne SDK 창 정상 오픈
- [ ] 결제 성공 → confirm API 호출 → `/orders/:id/complete` 라우팅
- [ ] PAY001 (금액 불일치) → inline error + 재조회 버튼
- [ ] PAY002 (PG 실패) → toast + 재시도
- [ ] C003 (소유권 위반) → 접근 거부 modal
- [ ] C004 (401 만료) → 로그인 페이지 강제 이동
- [ ] 팝업 차단 시 안내 UI

### 포인트
- [ ] 잔액 표시 정확
- [ ] 이력 조회 정상 (USE · EARN · CANCEL 구분)
- [ ] 결제 완료 후 잔액·이력 즉시 갱신

### 환불 (관리자 or 사용자 UI · 착수 시 정책 결정)
- [ ] 부분 환불 요청 폼 (금액 미입력 · 서버 산정)
- [ ] 잔여 수량 초과 시 명확한 메시지 (RF001)
- [ ] 환불 완료 후 잔액·재고·상태 갱신 확인

## a11y 특별 체크

- [ ] 모든 인터랙티브 요소 키보드로 접근 가능
- [ ] 포커스 표시 명확
- [ ] `<button>` vs `<div>` 적절 사용
- [ ] 폼 라벨(`<label htmlFor>`) · aria-label 존재
- [ ] 이미지 alt 텍스트
- [ ] 색상만으로 정보 전달하지 않음 (색맹 대응)
- [ ] 스크린 리더 (NVDA · VoiceOver) 실 검증
